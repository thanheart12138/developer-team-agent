# 实验现场压缩归档

本目录保存用户明确授权上传 GitHub 的已停止付费实验现场。每轮一个 `.tar.gz`，附同名 `.manifest.json`，记录文件清单、逐文件 SHA256、归档 SHA256 和原始相对目录。

归档前检查认证凭据与敏感文件；不包含 `.env` 或真实凭据。不改写本地原始证据。恢复时先验证校验和，再解压到独立目录，核对原数据库、工作区和计数；归档不授权自动启动任务或重置预算。

`editorial-platform-fullflow-20261010.tar.gz` 为183次请求实验的完整文件快照，包含数据库、账本、发送正文、Trace、检查点、生成产品、控制及统计脚本。模型历史内容作为原始证据保留，不代表其中所有判断均正确。
