## 机制验证

新增 `tests/test_context_slimming.py`，覆盖以下预期：

- 自测通过／失败及版本相符／不符：仅匹配的重复正文去重，协议与原请求对象保持；缺协议消息时继续提供正文。
- 旧报告引用：文件和哈希有效才精简；无效引用保留全文；真实报告可 read，原目标事实及账本保持，未自测仍拒绝提交。
- 接力筛选：当前失败关联文件及最近修改保留，省略正文可补读，仍在上下文的同版本范围继续拦截；诊断过期或无法定位时回退完整已知范围。
- 真实程序 Planner＋Fake 模型：正式文档可调查，刚 inspect 的正文进入下一次调用，后续改引用，原反馈只一份，原三次调查上限及测试／验证版本状态保持。
- 旧报告去正文后，任务焦点引用同步改为 `unit_test_feedback.detail_path`，不留下失效字段引用。
