每个文件串起问题、解决过程、方案取舍、方案测试和最终状态。同一问题继续更新原文件，保留旧测试条件及失败记录；新增架构问题才追加编号。代码和有效设计是实现依据，本目录负责说明演进与证据。

当前整理近期六项有直接证据的问题；项目更早阶段的架构决策尚未全面回溯，不代表所有历史架构问题已经补齐。普通入口路径 bug、非法单元 ID、单独提示词修改、验证脚本错误等通常不独立建档；只有形成可复用流程决策并有对比证据时才升级为架构问题。

测试记录分别注明机制测试、真实模型／工具、生成软件实际操作和用户验收。不同需求、不同结束状态的运行不作为严格成本 A/B；累计费用也不当成某个架构方案单独消耗。临时运行文件可能失效，现有项目证据文档保存结论和定位信息，原始运行数据尚未永久归档。
