# 011：真实模型质量与成本基线

状态：已执行并验证，含完整失败现场，待用户验收。

## 目标与可运行结果

管理平台能在明确外发范围和HTTP上限内运行真实DeepSeek thinking评测，形成可重跑的固定场景基线。重跑必须新授权，不默认自动循环。

## 范围与步骤

1. 从已确认预期选择有限集合，包含普通修复、跨文件修复及重要反例；固定代码起点、需求、独立原回归、工具环境、模型和版本。
2. 预检绿色与故障，明确完整调用预算（包含失败与重试）、外发数据及持久目录；用户批准后才发送。
3. 平台执行并保存全部请求／响应及工具证据，必要供应商协议历史保持完整。拒绝无授权或超预算运行。
4. 修复场景实际启动产品并做独立网页验证；拒绝／澄清案例核对轨迹，不以未生成网站判失败。
5. 使用010统计阶段开销，记录成功、停止、人工介入与已知局限。

## 完成条件与验证

- 一套有限真实案例完成到各自期望终点，或有完整失败现场；报告完成与产品成功分别记录。
- 修复成功必须同时满足任务结果、原独立回归和真实浏览器验证，不能只看模型自称或流程状态。
- 输出每例质量、HTTP、Token、阶段与耗时，失败不从总量中移除；单轮不宣称稳定成功率。
- 平台显示真实结果，持久预算对账；预算停止与未知用量正确展示。

## 边界与证据

不人工提示提交、不手改产品冒充自主修复；任何控制介入保留。缺授权完成其余预检后等待，不借旧额度。报告入口、复现命令、数据引用及ROADMAP同步。
