# 009：可操作的提示词管理页面

状态：已实现并验证离线管理闭环，待用户验收；真实批次启动入口见011。

## 目标与可运行结果

现有React／FastAPI中提供能实际操作的管理页面：查看提示词与版本、创建版本、比较差异、维护案例、运行离线评测、查看结果和受控激活。不交付静态页面冒充管理平台。

## 范围与步骤

1. 明确接口、文件写入与冲突处理、状态及激活门禁。建议文件为真实来源、不新增数据库表，待确认后实现。
2. 复用注册加载和评测器，后端校验而非仅前端限制；历史版本不可覆盖，不能由任意路径访问仓库。
3. 激活显示版本差异、评测依据和未解决问题，由用户明确操作；运行中的会话继续原绑定。
4. 展示失败、未执行、待人工判定和未知用量，不能统一成绿灯。

## 完成条件与验证

- 实际启动页面，经浏览器完成列表→新建版本→维护案例→离线评测→查看报告→激活符合条件的隔离测试版本。
- 验证重要失败拒绝、非法版本、哈希冲突、重复写入、越界路径、失败后可继续正常操作及旧会话不迁移。
- 使用隔离夹具进行激活测试，不为验证改正式激活版本或触发模型调用。
- 交付启动／操作说明及实际浏览器证据；页面能操作不等于真实模型效果通过。

## 边界与证据

不自动激活正式版本、不新增数据库schema、不修改密钥或配置。真实评测需要独立授权；不扩为多用户或独立服务。更新有效设计及ROADMAP。
