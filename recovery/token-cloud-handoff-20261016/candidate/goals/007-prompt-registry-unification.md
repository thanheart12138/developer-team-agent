# 007：统一提示词注册与兼容加载

状态：已实现并验证，待用户验收。

## 目标与可运行结果

所有模型指令模板从版本注册表加载，现有开发与连续返修仍能运行，旧会话仍能恢复原提示词。完成后提供可运行的注册表审计入口，输出调用位置、激活版本、历史版本及未登记指令；精确启动命令记录在交付说明中。当前入口为 `.venv/bin/python -m backend.app.runtime.prompt_registry`，实际审计证据见执行记录。

## 范围与步骤

1. 清点已注册14类、40份文件，以及返修、Worker和其他调用入口的内嵌指令、公共规则、工具说明。
2. 明确模板组合身份、变量、渲染结果与旧会话哈希映射，确认后更新有效设计。
3. 原文迁移并接通调用；工具参数schema和任务上下文保持各自身份，不强行作为提示词。
4. 增加审计入口，校验注册引用、模板哈希、变量和调用位置。创建版本不能覆盖历史文件。

## 完成条件与验证

- 审计实际运行，无未解释的内嵌模型指令；历史无调用模板明确标记用途。
- 对迁移前后同输入逐项比较渲染字节及组合哈希，差异全部解释，不同时优化文本。
- 验证旧绑定恢复、未知绑定拒绝、缺失变量、哈希不一致与当前新会话加载；有效工具协议保持。
- 不调用付费模型即可验证加载机制，不能据此宣称真实完成率改善。

## 边界与证据

不更换模型、删除思考历史、改业务或恢复独立模型审查。不自动续跑正式任务。补齐测试及审计结果、可执行命令、有效设计和ROADMAP；服务重启遵守任务检查规则。
