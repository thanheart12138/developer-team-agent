# 授权内范围搜索验证

用户确认实施成本诊断后的范围搜索方案。先更新有效Dev Design，search增加可选path指定授权文件或目录，省略保持全域输出和版本契约。范围只过滤原授权集合，不扩展文件权限；拒绝绝对路径、父目录逃逸、链接、空／缺失／无授权文件范围。分页版本绑定查询、规范范围和范围内文件哈希，换范围或改范围内文件后旧游标拒绝，范围外变动不使范围内分页失效。

新提示词说明已知模块位置时使用path；保留原无审查提示词常量。新会话绑定新提示词和SCOPED_SEARCH_SCHEMA，旧会话按原提示词选原SEARCH_SCHEMA，不迁移历史会话。默认全域仍可用，范围片段不冒充全文，必要缺失代码仍可读取。
