## 业务反例为何先搜索

两份原始响应的思考均先识别自动发布与显式状态操作冲突，明确应调用request_decision；随后选择搜索代码以充实影响说明，并把决策安排到后续响应。没有证据表明模型没理解需求或不知道工具。

已知契约冲突其实不依赖代码调查，但当前提示词允许必要调查，对「产品决策已充分依据」没有明确即时行动要求。另一方面，首响应探针只有1HTTP且不执行返回工具，因此不能把没有决策终点说成完整连续会话拒绝失败。对即时决策预期未达成、对后续行为未验证，二者必须分开。可建议强调证据充分的业务冲突直接request_decision，但本轮不再修改候选或追加测试。
