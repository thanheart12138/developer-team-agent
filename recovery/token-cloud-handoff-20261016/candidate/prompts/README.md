# Prompt Registry

每个提示词使用 `prompts/<name>/vN.md` 保存不可变版本，`registry.json` 只指定当前激活版本及模板 SHA-256。

修改提示词时新增版本文件，计算并登记新哈希，再切换 `active`。不要覆盖已经参与过测试的版本文件。运行时会在调用前校验哈希；不一致时停止调用。动态内容只通过 `{{variable}}` 显式渲染，运行 Trace 记录名称、版本、模板哈希、渲染后哈希和运行上下文哈希。

`evaluations/` 保存可比较的场景结果。每次提示词升级使用同一需求、模型、预算和测试控制，新增一份结果文件；先比较是否完成、终止阶段和通过单元数，再在完成度不下降的前提下比较总 Token、HTTP 次数和阶段 Token。历史运行没有提示词身份字段时可登记为回填基线，但后续正式对比必须直接使用 Trace 中的版本与哈希。
